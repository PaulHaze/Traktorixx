This repo is a little project to make a custom skin for the dj software Mixx. I am coming from a another piece of DJ software called traktor and I want to make Mixx resemble as close as possible to traktor. I have included some pictures of key parts of the software I want to try and emulate. 

There is an official guide for making skins here:
https://github.com/mixxxdj/mixxx/wiki/Creating-Skins

Someone has already begun something similar and there are 2 similar repos I found which are located here:
/Traktmixxx
/Traktmixxx-RAW

The code for this repo will be stored in 
/custom_taktor_skin

Some reference images of what verious Traktor elements look like can be found here:
/custom_taktor_skin/target_images/

Initially I want to copy over the most accurate or recent ui repo from the ones above. From there I want to modify in targeted adjustments to eventually get the look I want.
